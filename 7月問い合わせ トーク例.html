7月問い合わせ・最初は口が重いご家庭

最初は情報を出さない保護者が、聞き方しだいで少しずつ状況を話し、自分から「必要かも」と思うまでの通話例。

ご家庭の設定

問い合わせ
7月にWebから資料請求。当時の電話は「資料を見て検討します」で落とし
お子さま
中学2年生・男の子（ハルトくん）／サッカー部
前回のメモ
ほぼなし（きっかけ・成績の記録なし）
保護者の様子
お母さま。最初は「まあ…」「特には」と口が重く、聞かれたことにだけ答える
最初は言わない
本当の状況
  • 夏休みは部活中心で、家での勉強はほぼなし
  • 2学期中間で数学が 64点 → 52点
  • 本人は「次は頑張る」と言うだけ
  • 期末は11月下旬、12月に三者面談
架電のタイミング
10月下旬（中間テストが返ってきた頃）
OPこちらのトーク（メイン） 保護者ご家庭の反応
  1. 0 オープニング
  2. 1 前回理由の深掘り
  3. 2 変わってない現状
  4. 3 未来の予定
  5. 4 検討のお願い
  6. 5 日程調整
STEP 0オープニング

ねらい電話した理由と、話を聞く理由を最初の30秒で伝える

OP

お世話になっております。個別教室のトライの〇〇と申します。山田様のお電話でお間違いないでしょうか？

保護者

…はい、そうですけど。

OP

7月にお問い合わせいただいていたので、ご連絡させていただきました。ちょうどこの時期は、2学期の中間テストが返ってきたタイミングで、同じ中学2年生のご家庭からのご相談が増えていまして、山田さんもその後いかがかなと思い、ご連絡しました。今2,3分お時間よろしいですか？

保護者

ああ…少しなら大丈夫です。

STEP 1前回理由の深掘り

ねらい7月というだけで期末とは決めつけず、きっかけから聞く。止まったら例示で選んでもらう

OP

ありがとうございます。7月にお問い合わせいただいたときは、どんなことがきっかけでしたっけ？

保護者

うーん、まあ…いろいろですけど。

OP

そうですよね。お母さまのイメージで大丈夫なんですけど、例えば期末テストの結果が気になったとか、夏休みの過ごし方が気になったとか、どちらかというと近いのはありますか？

保護者

どっちかというと夏休みですかね。家で全然やらないので。

OP

あ〜、多いですよね。部活があると、なかなか家で机に向かう時間って取れないですよね。テスト前もあまり勉強しない感じでしたか？

保護者

そうなんです。部活が忙しくて、テスト前日にちょっとやるくらいで…

STEP 2変わってない現状ヤマ場

ねらい三択で選んでもらい、事実と本人の様子を聞いて、最後に要約で「変わってない」を保護者の口から

OP

その時気になっていたところは、今はいかがですか？良くなってきた、変わらない、ちょっと厳しくなった、でいうとどれが近いですか？

保護者

…変わらない、ですかね。正直。

OP

言いにくいことまでありがとうございます。ちなみに中間テストは、もう結果が返ってきました？

保護者

返ってきました。数学が1学期より下がっちゃって。60点台だったのが50点ちょっとで…

OP

そうだったんですね。ご本人は、どんなふうに言ってます？

保護者

「次は頑張る」とは言うんですけど、結局やってないんですよ。夏休みも部活ばっかりで。

OP

少し整理させてください。7月の時点で気になっていたおうちでの勉強の習慣は、夏を越えても変わっていなくて、中間では数学が下がってしまった、ということですね。

保護者

そうですね…結局あの時から変わってないです。

STEP 3未来の予定ヤマ場

ねらい仮定ではなく予定で聞き、残り時間に保護者自身で気づいてもらう

OP

次の期末テストっていつ頃でしたっけ？

保護者

11月の終わりだったと思います。

OP

じゃあ、あと5週間くらいですね。

（2〜3秒、間を置く）

OP

そこに向けては、何かお考えになっていることってあります？

保護者

…いや、特には。このままだと同じことになりそうですよね。12月には三者面談もあるし…

OP

7月から3か月経って、期末まであと5週間…気がかりですよね。

保護者

そうなんですよ。

STEP 4検討のお願い

ねらい冒頭の「ご相談が増えている」を回収し、お願いの形で言い切る

OP

冒頭でお伝えしたように、皆さん「このままで大丈夫か確認したい」という方が多いんです。山田さんも、少しでも気になっているようでしたら、一度学習相談で確認してみてください。

保護者

そうですね…

STEP 5日程調整

ねらい一度引いてから絞る。探す途中で「埋まっている」を伝えて一枠だけ出し、変更の逃げ道を残して取っておく

OP

とはいえ、今すぐにというわけにもいかないと思います。お子さまと相談する材料に、空いている日程を先にお伝えしておきますね。ある程度絞ってお伝えしようと思いますが、平日と土日ですと、どちらが動きやすいですか？

保護者

平日は部活があるので、土日ですかね。

OP

土曜と日曜ですと、どちらがよろしいですか？

保護者

日曜の午後なら。

OP

承知しました。日曜の午後ですと、期末前でご相談が多くて直近はかなり埋まっているんですが…ちょうど11月1日の14時でしたら一枠だけ空いていますね。

保護者

じゃあ、そこで。

OP

ありがとうございます。では11月1日（日）14時でお取りしておきます。変更はフリーダイヤルにご連絡いただければ大丈夫なので、ハルトくんとも相談してみてください。前日に一度、確認のご連絡をさせていただきます。

保護者の口がひらいていく流れ

  1. 最初は　「…はい、少しなら」
  2. 例示で選んでもらうと　「家で全然やらないので」
  3. 三択で聞くと　「変わらない、ですかね」
  4. 事実を聞くと　「数学が下がっちゃって」
  5. 本人の様子を聞くと　「結局やってない」
  6. 予定を聞いて黙ると　「このままだと同じことに…三者面談もあるし」

数学の下がり幅、三者面談、「このままだとまずい」に近い一言は、どれもOPからは言わず、保護者の口から出ている。
